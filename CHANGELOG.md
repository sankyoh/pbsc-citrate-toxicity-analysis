# Changelog

## 1.1.0 - 2026-08-28

- Added the R scripts used to reproduce the final three-group descriptive
  tables and the categorical and continuous-exposure Firth-type modified
  Poisson analyses.
- Documented the final analysis hierarchy: adjusted Firth-type estimates as
  the primary analysis, crude Firth-type estimates as supporting results, and
  conventional modified Poisson estimates as method-sensitivity analyses.
- Documented R and package versions, covariate standardization, exposure
  scaling, reconstructed Wald p-values, expected checks, and execution order.
- Updated terminology from "severe" to "marked" for the post hoc electrolyte
  thresholds.
- Removed the superseded exploratory Stata analysis from the release scope.
- No participant-level data or generated analysis outputs are included.

## 1.0.0 - 2026-07-02

- Initial public release of selected Stata analysis-support files.
